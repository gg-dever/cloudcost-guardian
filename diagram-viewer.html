2. Data Flow Sequence

Flow: EventBridge triggers Cost Analyzer → fetches from Cost Explorer → stores in DynamoDB → Forecaster runs → Recommender analyzes → Notifier detects anomalies and sends alerts.

4. DynamoDB Schema Design

Design: Optimized for time-series queries with service-level granularity. Single-table design with GSI for efficient access patterns and automatic TTL cleanup.
graph TD subgraph "cost_history Table" H1[PK: SERVICE#service_name] H2[SK: DATE#YYYY-MM-DD] H3[Attributes: cost, unit, region, timestamp] H4[TTL: 90 days] H5[GSI: date-service-index] end subgraph "cost_anomalies Table" A1[PK: ANOMALY#type] A2[SK: DATE#YYYY-MM-DD#service] A3[Attributes: severity, threshold, actual_cost] A4[TTL: 30 days] end subgraph "cost_recommendations Table" R1[PK: RECOMMENDATION#type] R2[SK: DATE#YYYY-MM-DD] R3[Attributes: priority, impact, description, roi] R4[TTL: 60 days] end H1 --> H2 H2 --> H3 H3 --> H4 H4 --> H5 A1 --> A2 A2 --> A3 A3 --> A4 R1 --> R2 R2 --> R3 R3 --> R4 style H1 fill:#4053D6,stroke:#232F3E,stroke-width:2px,color:#fff style A1 fill:#4053D6,stroke:#232F3E,stroke-width:2px,color:#fff style R1 fill:#4053D6,stroke:#232F3E,stroke-width:2px,color:#fff
